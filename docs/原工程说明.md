# 微缩奇案 MiniCase

PICO Project Swan 上的 MR 推理游戏。案发现场按 1:20 缩小，摆在玩家真实的桌面上；玩家用两根手指拉开抽屉、掀开屋顶、把证物拿到眼前转着看，捏一下小人偶向他问话，在「案情板」上把线索联系起来，最后指认真凶。

## 玩法

- **现场**（Stage，混合现实）：现场模型放在玩家正前方，先读取头显朝向摆正；如果头显识别到真实桌面（PlaneTrackingManager，TABLE 标签或朝上的水平面），就摆在桌面上，识别不到就用默认高度 80 厘米。
  - 捏住抽屉、柜门、箱盖往外拉，拉过一半松手就会自己打开。
  - 捏住屋顶（第 2、3 案）往上提，整块顶盖会掀到一边。
  - 捏起小物件，它会飞到玩家面前放大到 13 厘米；捏住左右、上下拨动可以转着看。有的线索藏在背面、底部或口袋里，要转到对着自己才会出现。
  - 捏一下小人偶，右侧弹出问话面板。找到相关线索后，会解锁新的问题。
- **案情板**（窗口）：
  - 「线索」页：物证、证词、推论分组显示，捏两张卡片就把它们联系起来，有关联的会得出新推论。
  - 「问话记录」页：所有问过的问题和回答。
  - 「指认真凶」页：选择是谁、动机、最有力的证据。指认错了会说明原因，不扣分。
- **卷宗**（窗口）：切换案件、查看在场人物、要提示、从头再查、调台面高度、开关音乐。
- 场景里常驻两个入口：右前方的「案情板」标签，左前方的「菜单」（提示、两个窗口、摆到正前方、从头再查、退出）。

## 四个案子（人物、店铺、案件均为虚构）

| | 案子 | 场景 | 嫌疑人 | 线索数 |
|---|---|---|---|---|
| 1 | 梧桐里的怀表（教学） | 1930 年代上海石库门，前排客堂、灶披间，后排抬高的前楼、亭子间 | 林太太、阿福、陈先生（委托人周先生） | 18 |
| 2 | 听雨客栈的银票 | 清末江南古镇客栈，前排大堂、灶房，后排两间客房，盖着可以掀开的屋顶 | 钱掌柜、小六、吴先生、郑小姐（委托人赵老板） | 18 |
| 3 | 夜车上的翡翠 | 1930 年代沪宁夜车头等卧铺车厢，四个包厢加乘务员室，车顶和上半截车厢可以掀开 | 老孟、白先生、许医生、苏小姐（委托人沈老板） | 17 |
| 4 | 戏园后台的凤冠 | 1930 年代北平戏园，前排管箱房、化妆间、琴房，后排抬高的戏台（出将、入相、守旧幕布） | 老葛、小马、芸姐、钟先生（委托人霍班主） | 19 |

每个案子的结构：
- 物证来自现场的部件；
- 证词来自问话，有的问题要先找到相关物证才能问；
- 推论由两条线索联系得出。

指认需要三样：凶手、一条动机线索、一条证据线索；每样都有多条线索可以通过，按提示一步步走只需 6 到 14 步。

## 代码结构

- `core/`：纯 Kotlin 的规则，不依赖 SDK，全部有单元测试。
  - `Case.kt`：数据结构（部件、人物、问题、线索、推论、答案）。
  - `Cases.kt`：四个案子的完整剧本。
  - `Investigation.kt`：调查进度、提示、指认、存档。
  - `Casebook.kt`：多个案子的进度和解锁。
- `render/`：
  - `Diorama.kt`：现场模型、打开、掀起、拿起、转动、提示箭头。
  - `Layouts.kt`：抽屉、门、盖子怎么动。
  - `TableFinder.kt`：桌面识别。
  - 另有音效、背景音乐、粒子。
- `content/`：
  - `CaseStage.kt`：手势，以及和鲁班机关匣相同的松手判定：两指张开 3 帧即松手，另有 2 秒看门狗。
  - `ScenePanels.kt`：场景里的面板。
  - `BoardWindow.kt`、`FileWindow.kt`：两个窗口。
- `game/Game.kt`：场景和窗口共享的状态。
- `game/AutoPilot.kt`：调试版的自动破案钩子，供模拟器测试用（logcat 标签 `CaseTest`）。
- 手势日志标签 `CaseInput`，现场摆放日志标签 `CaseStage`、`CaseTable`，正式版也保留。

## 素材

见 `docs/素材来源.md`。

## 构建

```bash
cd app
JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.12.1+1 ./gradlew --no-daemon testDebugUnitTest assembleDebug assembleRelease
```

模型重新生成（在工作区根目录运行）：

```bash
tools/blender/prep_minicase.sh
blender -b --factory-startup --python Pico_Vibe_Lab/MiniCase/tools/make_cases.py -- Pico_Vibe_Lab/MiniCase/app/app/src/main/assets/models --preview
```
